## 💡 Sobre

Baixar vídeos, arrumar uma pasta bagunçada, diagnosticar um PC lento… tarefas pequenas que se repetem e tomam tempo. Este repositório reúne **scripts de automação em Python** que resolvem essas tarefas com poucos comandos, para você **trabalhar menos e fazer mais**.

⚡ Rápido de usar &nbsp;•&nbsp; 🧱 Projetos independentes &nbsp;•&nbsp; 🆓 Código aberto

---

## 🧩 Projetos

| | Projeto | O que faz |
|:-:|---------|-----------|
| 📥 | [**Downloader-Youtube**](./Downloader-Youtube) | Baixa vídeos e áudios do YouTube |
| 🗂️ | [**Organizador**](./Organizador) | Organiza arquivos e pastas automaticamente |
| 🛠️ | [**Tecnico-PC**](./Tecnico-PC) | Ferramentas de apoio para diagnóstico e manutenção de PCs |

> Cada pasta é um projeto independente, com seu próprio código e dependências.

> Os nomes dos arquivos podem variar de projeto para projeto — veja o conteúdo de cada pasta.
